<p>ADBlocker блокирует рекламу и трекеры в приложениях Android по спискам фильтров для браузерных блокировщиков рекламы, таким как EasyList, uBlock Origin и AdGuard. Можно выбрать приложения для фильтрации или фильтровать все личные приложения. ADBlocker работает локально, скачивает только списки фильтров, на которые вы подписаны, и не отправляет телеметрию.</p>

<p>Есть два способа фильтрации.</p>
<ul>
<li><b>Режим root</b> (нужен root-доступ, например через KernelSU, Magisk или APatch, и Android 12 или новее с ядром GKI). ADBlocker настраивает этот режим с root-доступом без перезагрузки и без изменения /system. Системный слот VPN в Android остаётся свободным для другой VPN, и каждое соединение по-прежнему относится к приложению, которое его установило.</li>
<li><b>Режим VPN</b> (без root, Android 10 или новее). Трафик фильтруемых приложений проходит через локальную VPN ADBlocker.</li>
</ul>

<p>При включённой фильтрации по URL ADBlocker применяет правила для URL, ресурсов и скрытия элементов страниц внутри HTTPS-соединений через локальный центр сертификации, ключ которого остаётся на устройстве. В режиме root ADBlocker делает сертификат этого центра доступным фильтруемым личным приложениям. В режиме VPN вы устанавливаете сертификат самостоятельно, и его принимают только приложения, которые доверяют пользовательским сертификатам. До установки, а также для приложений, которые отклоняют сертификат, HTTPS остаётся зашифрованным и действуют только правила для доменов. Можно отключить фильтрацию по URL, чтобы фильтровать только по доменам.</p>

<p>Возможности</p>
<ul>
<li>Выбор отдельных приложений или фильтрация всех личных приложений с исключениями. При наличии root-доступа можно фильтровать приложения рабочего профиля</li>
<li>Фильтрация незашифрованного DNS наряду с правилами для доменов, URL и скрытия элементов страниц</li>
<li>Подписки на списки фильтров EasyList, uBlock Origin и AdGuard, свои правила и доверенные сайты</li>
<li>Запись запросов фильтруемых приложений, чтобы проверять сработавшие правила и блокировать или разрешать домены</li>
<li>Пауза фильтрации для одного приложения или для всех и значок на панели быстрых настроек</li>
</ul>

<p>В режим root входит модуль LSPosed/Vector, который используется только там, где приложение само проверяет сертификаты. Поддерживаются только 64-битные устройства на базе ARM и x86.</p>
